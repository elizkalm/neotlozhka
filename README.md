# Маркетинг-неотложка — лендинг

Статический сайт: HTML + CSS + немного JS. Ни сборки, ни зависимостей —
файлы из этой папки отдаются как есть.

## Запуск локально

Открыть `index.html` в браузере. Больше ничего не нужно.

## Что где

| Файл | Что внутри |
|---|---|
| `index.html` | Вся страница и модалки |
| `styles.css` | Токены в `:root` и стили; имена переменных повторяют имена стилей Figma |
| `script.js` | Вкладки услуг, модалки, листание кейсов, мобильное меню |
| `privacy.html` | Политика конфиденциальности — **заглушка**, текст должен утвердить владелец |
| `img/` | Картинки: .webp для показа, .jpg запасной для первого экрана |
| `_backend/apps-script.gs` | Приёмник заявок: Google-таблица + Telegram. Внутри инструкция по подключению |

## Чего в вёрстке пока нет

- **Подключённого приёмника заявок.** Код готов с обеих сторон, но адрес ещё не вставлен: в `script.js` переменная `FORM_ENDPOINT` пуста. Пока она пустая, форма показывает «заявка принята», но никуда не отправляет.
- **Скриншотов кейсов** — в модалках стоят пустые плашки.
- **Секции «Чем мы отличаемся»** — не утверждена, в вёрстку не бралась.
- **Фотографий команды** — на бейджах те, что были в макете.
